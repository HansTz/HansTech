# <div align='center'>Creepy Baileys</div>

Crepy Baileys is a WebSockets-based TypeScript/Javascript library for interacting with the WhatsApp Web API.


> You might want to use **[creepy-baileys@1.0.0](https://www.npmjs.com/package/creepy-baileys/v/1.0.0)** which has lts as it was fixed before official baileys was fixed.
